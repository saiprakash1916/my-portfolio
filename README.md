# Sai Prakash Portfolio

A modern, responsive portfolio built with React, Vite, Three.js, and Tailwind CSS. It showcases my projects, technical skills, and professional experience as a Senior Java Developer.

## 🚀 Tech Stack

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Three.js
- Framer Motion
- EmailJS

## ✨ Features

- Responsive Design
- Interactive 3D Hero Section
- Smooth Animations
- Projects Showcase
- Skills Section
- Contact Form (EmailJS Integration)

## 🛠️ Installation

Clone the repository

```bash
git clone https://github.com/saiprakash1916/my-portfolio.git
cd my-portfolio
```

Install dependencies

```bash
npm install
```

Create a `.env` file in the project root using the following template:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```

Start the development server

```bash
npm run dev
```

## 📄 Environment Variables

This project uses **EmailJS** for the contact form.

Create a `.env` file in the project root with the following variables:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```

> **Note:** Never commit your `.env` file to GitHub. Only commit a `.env.example` file if you want to share the required environment variable names.
