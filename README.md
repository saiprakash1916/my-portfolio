# My Portfolio

A modern, responsive portfolio built with React, Vite, Three.js, and Tailwind CSS. It showcases my projects, technical skills, and professional experience as a Java Full Stack Developer.

## 🚀 Tech Stack

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Three.js
- Framer Motion
- EmailJS

## ✨ Features

- Responsive Design
- Interactive 3D Hero Section
- Smooth Animations
- Projects Showcase
- Skills Section
- Contact Form

## 🛠️ Installation

```bash
git clone https://github.com/saiprakash1916/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```
