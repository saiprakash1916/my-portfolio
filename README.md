# 🚀 Sai Prakash | Portfolio

A modern developer portfolio built with **React**, **Vite**, and **Tailwind CSS** to showcase my experience, skills, and projects.


## ✨ Features

- Responsive modern UI
- Smooth animations
- Interactive project showcase
- Experience & Skills section
- Resume download
- Contact section

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- Framer Motion
- React Router
- Three.js

## 📂 Project Structure

```
src/
├── assets/
├── components/
├── constants/
├── hooks/
├── layout/
├── pages/
└── App.jsx
```

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/saiprakash1916/my-portfolio.git
```

Go to the project directory

```bash
cd my-portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
